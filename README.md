## 🌟 Key Features

This portfolio is engineered with a suite of advanced features for an immersive and informative experience:

*   **Interactive Starfleet UI/UX**: Implements LCARS (Library Computer Access and Retrieval System) design principles for a futuristic interface. ✨
*   **Dynamic 3D Visuals**: Features a procedural 3D warp starfield, an animated warp tunnel canvas, and subtle gravity lens & tachyon SVG distortion filters.
*   **Tactical Targeting HUD Cursor**: A custom, interactive cursor enhances the Starfleet experience.
*   **Warp Core Spool-up Boot Sequence**: An engaging preloader sequence simulating a starship boot-up. 💥
*   **"Orbital Missions" Display**: Showcases various projects (missions) with detailed logs, flight telemetry, and tech conduits used. Includes a classification filter and interactive modal for each mission.
*   **"Ship's Computer" Interface**: An interactive AI console for querying diagnostics on the warp core, architecture, neural plumes, and data persistence.
*   **"Conduit Telemetry" Overview**: Visually presents technical proficiencies across mobile, backend, and AI sectors, highlighting skills like Kotlin, Jetpack Compose, Clean Architecture, TFLite Edge AI, Firebase, Python, TypeScript/React, GitHub Actions, and Cybersecurity. ⚡
*   **"Communications Relay"**: Provides direct quantum channels for contact (phone, WhatsApp), quick actions to GitHub and Gravatar, and a grid of subspace communication arrays (social links).
*   **Printable "Starfleet Engineer Dossier"**: Generates a professional, print-friendly PDF of the engineer's CV.
*   **Procedural Web Audio Synthesizer**: Custom audio effects for warp engagement, sensor ticks, computer chirps, and gravity distortions for an enhanced immersive experience. 🔊
*   **LCARS Command Palette (Ctrl+K)**: A quick access command menu for rapid navigation and execution of ship functions.
*   **Responsive Design**: Built with Tailwind CSS for seamless adaptability across various starship bridge displays and personal devices.
*   **Single-File Build**: Utilizes `vite-plugin-singlefile` to bundle the entire application into a single `index.html` for easy deployment.

## 🚀 Installation

To get the U.S.S. KOTLIN running on your local workstation, follow these directives:

1.  **Clone the Repository**: Retrieve the project files from the Starfleet GitHub array.
    ```bash
    git clone https://github.com/Dev-moe-kyawaung/moekyawaung-developer-portfolio-64.git
    cd moekyawaung-developer-portfolio-64
    ```

2.  **Install Dependencies**: Deploy the necessary modules for all primary conduits.
    ```bash
    npm install
    ```

3.  **Run in Development Mode**: Activate the development server for real-time adjustments.
    ```bash
    npm run dev
    ```
    The application will typically be accessible at `http://localhost:5173`.

4.  **Build for Production**: Compile the optimal single-file build for interstellar deployment.
    ```bash
    npm run build
    ```
    This command will generate a highly optimized `dist/index.html` file, containing all assets embedded for single-file deployment.

5.  **Preview Production Build**: Test the deployed artifact before final transmission.
    ```bash
    npm run preview
    ```
